문제

종이 한 장이 놓치면 안 되는 일 여러 개를 품고 있습니다

안내문은 "읽기"보다 "그날 행동으로 옮기기"가 어렵습니다. 날짜는 적어 두어도, 준비물·회신·출발 시각은 결국 머릿속에 남겨 두게 됩니다.

학부모 김OO 님

초등 2학년 · 맞벌이

"가방 속 가정통신문을 금요일 밤에야 봤어요. 회신서는 이미 마감이었죠."

  • 일주일에 3~5장씩 오는 가정통신문, 아이 가방 속에서 구겨지고 사라짐
  • 회신서 서명·제출 기한, 체험학습비 계좌·금액을 따로 기억해야 함
  • 체험학습 당일 아침: 도시락·우산 챙겼나? 몇 시에 나가야 하나?

① 문서 인식📐

기울어진 사진 반듯하게

문서 모서리를 찾아 원근 보정, JPG·PDF로 저장. 어긋나면 모서리를 끌어서 조정.

① 문서 인식🔍

흐림·중복 감지

흐린 사진은 "다시 찍어 주세요", 이미 올린 문서는 중복 등록 전에 알려 줌.

② 분석✅

할 일 · 마감 · 준비물

요약, 할 일, 날짜·시간, 장소, 준비물 체크리스트를 한 번에. 근거 문장도 함께 표시.

② 분석✍️

회신서 · 납부 정보

서명 후 제출할 회신서와 기한, 체험비 금액·계좌를 따로 뽑아 놓치지 않게.

② 분석🪜

거꾸로 짜는 학습 계획

대학생 과제는 마감에서 거꾸로 "구현 → 실험 → 보고서 → 제출" 단계 일정을 제안.

② 분석🌏

다국어 · 쉬운 말 요약

다문화 가정과 어르신도 이해하도록 번역·쉬운 말로 다시 요약.

③ 날씨☂️

비 오면 우산 자동 추가

행사 장소의 그날 예보로 우산을 준비물에 넣고, 기온에 맞는 옷차림을 조언.

④ 이동⏰

출발 시각 · 출발 알람

장소까지 소요시간 + 여유 시간으로 출발 시각을 계산하고, 당일 교통에 맞춰 다시 계산.

공통🌅

아침 브리핑 알림

오늘 할 일 · 날씨 · 출발 시각 · 준비물을 아침에 한 번에.

공통🗂️

문서함 · 검색

스캔한 원본을 보관하고 제목·내용으로 검색. 캘린더와 연결.

공통📆

.ics 내보내기 · PWA

휴대폰 기본 캘린더로 옮겨 탭이 닫혀도 알람. 홈 화면에 추가해 앱처럼.

공통🧪

예시 체험 모드

API 키 없이도 학부모·대학생 예시 문서로 전 과정을 바로 체험.

차별점

"문서 → 일정"이 아니라 "문서 → 그날의 행동 계획"

캘린더 앱은 날짜를 기억해 주고, 스캐너 앱은 종이를 저장해 줍니다. 그 사이의 "그래서 그날 나는 뭘 해야 하지?"를 채우는 것이 문서 비서입니다.

📅 일반 캘린더 · 📠 스캐너 앱

문서→일정 1개
  • 날짜를 사람이 직접 옮겨 적어야 함
  • 준비물·회신서·납부는 메모로 따로
  • 날씨·출발 시각은 당일 아침 각자 확인
  • 스캔은 보관만, 내용은 이해하지 않음

📄 문서 비서

문서→할 일 · 회신 · 납부→그날의 행동 계획
  • 사진 한 장으로 할 일·마감·준비물 자동 정리
  • 그날 날씨를 보고 우산·옷차림까지 반영
  • 장소까지 이동 시간으로 출발 시각과 알람 계산
  • 대학생 과제는 마감에서 거꾸로 단계 계획

🤝 AI는 제안, 결정은 사용자

AI가 뽑은 할 일은 바로 저장하지 않고 확인 화면에서 고치고 고른 뒤 저장합니다. 확신이 낮은 항목은 따로 표시합니다.
