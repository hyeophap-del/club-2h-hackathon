# 문서 비서

사진 속 문서를 스캔해 PDF·JPG로 저장하고, 문서가 **어느 날짜에 필요한지** 읽어낸 뒤, 오늘과 그날의 **날씨**를 알려주는 웹사이트입니다. HTML과 순수 JavaScript로 만들었고 서버 없이 브라우저에서 동작합니다.

## 세 에이전트

| 에이전트 | 하는 일 | 파일 |
| --- | --- | --- |
| 1. 문서 스캔 | 사진에서 문서 테두리를 자동으로 찾고(OpenCV.js), 원근을 펴서 반듯한 문서로 만든 뒤 보정(선명한 컬러·회색조·흑백)하고 PDF·JPG로 저장합니다. 여러 쪽을 모아 PDF 한 파일로 만들 수 있습니다. | `js/scanner.js` |
| 2. 날짜 읽기 | 스캔한 문서의 글자를 인식(Tesseract.js, 한국어+영어)하고 날짜 표현을 모두 찾아, 주변 문맥(마감·일시·발행 등)으로 이 문서가 필요한 날짜와 D-day를 고릅니다. | `js/ocr.js`, `js/dates.js` |
| 3. 날씨 | 오늘의 기온·체감온도·강수확률·습도·바람·미세먼지·자외선과 시간별·7일 예보를 보여 주고, 옷차림·우산 조언을 합니다. 2번이 찾은 날짜의 예보도 함께 보여 줍니다(16일 이내). | `js/weather.js` |

`js/app.js`가 세 에이전트를 이어 줍니다: 스캔 → 날짜 읽기 → 그날 날씨.

## 실행

카메라·위치 권한과 Tesseract 작업자 때문에 `file://`보다 로컬 서버로 여는 편이 안정적입니다.

```bash
python -m http.server 8000
# 브라우저에서 http://localhost:8000
```

GitHub Pages에 그대로 올려도 동작합니다.

## 날짜 분석이 인식하는 형식

- `2026년 11월 27일(금)`, `2026.11.27`, `2026-11-27`, `2026/11/27`, `26.11.27`
- `11월 24일`, `11/24(화)`, `2026.10.01 ~ 10.31` 같은 기간
- `Dec 3, 2026`, `3 Dec 2026`
- `오늘`, `내일`, `모레`, `3일 후`, `다음 주 수요일`
- 날짜 뒤의 시간: `오전 9시 30분`, `18:00`, `2:00 PM`

`까지·마감·제출·납부`는 제출·마감일, `일시·행사·회의·시험`은 행사·일정일, `발행·작성·발급`은 발행일로 분류하고, 다가오는 날짜와 구체적인 시간이 있는 날짜에 점수를 더 줍니다. 목록에서 다른 날짜를 누르면 그 날짜 기준으로 날씨를 다시 보여 줍니다.

## 개인정보

사진과 인식한 글자는 브라우저 안에서만 처리되며 서버로 보내지 않습니다. 날씨 조회에는 고른 위치의 좌표만 Open-Meteo에 보내고, "내 위치"를 누르면 지역 이름 확인을 위해 BigDataCloud에도 좌표를 보냅니다.

## 사용한 라이브러리

- [OpenCV.js](https://docs.opencv.org/) 4.9.0: 문서 테두리 인식
- [Tesseract.js](https://github.com/naptha/tesseract.js) 5.1.1: 글자 인식
- [jsPDF](https://github.com/parallax/jsPDF) 2.5.1: PDF 만들기
- [Open-Meteo](https://open-meteo.com/): 날씨·미세먼지·도시 검색 (API 키 불필요)
